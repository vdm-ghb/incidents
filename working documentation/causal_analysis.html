The Causal Theme Map is an internal exploratory view for finding and comparing recurring wording patterns in the incident database. It separates candidate recorded causal statements from learning themes in lessons and actions. It is a route into the record text, not a causal model: each relationship is source-unlinked and must be reviewed against a cited source before use as a finding.

Candidate output — not verified fact. Themes are keyword-matched from each record's own text. A match in what went wrong is a candidate recorded causal statement; a lesson or action is not treated as a cause. Incidental background-only matches are excluded.
